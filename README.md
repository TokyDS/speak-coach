# Speak Up — тренажёр разговорного английского

Говоришь в микрофон — собеседник Alex отвечает голосом и задаёт следующий вопрос.
После каждой твоей реплики:

- **что услышал распознаватель** — твоими же словами, с ошибками как есть; слова, в которых
  Whisper сомневался, подчёркнуты: нажми — и сравни свой вариант с правильным;
- **правка как корректура**: зачёркнуто то, что неверно, подчёркнуто то, что добавить (go → **went**, **the** cinema);
- **как сказал бы носитель** — с переводом, кнопками «Послушать», «Повторить вслух» (процент совпадения,
  пропущенные слова подчёркнуты) и «В тетрадь»;
- **уровень фразы** по шкале CEFR (A1–C2) и короткие объяснения ошибок по-русски;
- **темп речи** в словах в минуту (носители в разговоре — примерно 130–160).

«Не знаю, что сказать» — три варианта начала ответа с переводом. «Завершить» — итоги: уровень в этом
разговоре и что нужно для следующего, что получилось, повторяющиеся ошибки на твоих примерах и фразы на
следующий раз.

Разговоры: свободная болтовня, K-pop/дорамы/кино, собеседование на .NET-разработчика, интервью
в магистратуру в Корее, поездка в Сеул, рабочий созвон, «поспорь со мной».

## Уровни

- **Твой уровень** — медиана оценок последних 30 развёрнутых реплик (короткие «Yes, I do» не оцениваются).
  На старте видно, сколько реплик уже звучит на следующем уровне. Пока реплик меньше пяти, считается B1;
  уровень можно выбрать и вручную.
- **Собеседник** говорит на твоём уровне («как я»), на ступень проще или сложнее — от A2 до C1:
  меняются словарь, длина фраз, идиомы и темп.

## Тетрадь фраз

Исправленные фразы и полезные выражения из разговора и итогов кладутся в тетрадь кнопкой «В тетрадь».
Повторение вслух: видишь фразу по-русски, говоришь по-английски, тренажёр сверяет. Верно — фраза вернётся
через 1, 3, 7, 16, 35, 90 дней; с ошибкой — снова сегодня. Если ответ верный, но другими словами, его можно
засчитать вручную.

## Прогресс

Дни подряд, минуты речи, темп, доля реплик без ошибок и уровень по дням за 30 дней — на графиках и таблицей.
Разговор сохраняется после каждой реплики, так что закрытая вкладка ничего не теряет.

## Как это устроено

Всё, кроме ответов Claude, работает локально:

| Шаг | Чем | Время на этом ноутбуке |
|---|---|---|
| Распознавание речи | faster-whisper `small.en`, CPU | ~2 с |
| Ответ собеседника | постоянный процесс `claude -p` на разговор, ответ потоком | первое предложение через 1.5–3 с |
| Голос собеседника | Piper `en_US-lessac-medium`, по предложениям | <0.5 с на предложение |
| Разбор и уровень | отдельный вызов `claude -p`, параллельно с ответом | приходит следом, пока слушаешь Alex |

Claude работает через установленный Claude Code — **по твоей подписке, без API-ключа**. Даже если в окружении
окажется `ANTHROPIC_API_KEY`, тренажёр его не передаёт, чтобы запросы не стали платными. Записи голоса
никуда не сохраняются; в Claude уходит только распознанный текст. Данные лежат в `~/.local/share/speak-coach/`:
`sessions/` — разговоры, `phrasebook.json` — тетрадь.

## Установка (один раз)

```bash
git clone https://github.com/TokyDS/speak-coach.git && cd speak-coach
python3 -m venv .venv && .venv/bin/python -m pip install -r requirements.txt
ln -s "$PWD/bin/speak" ~/.local/bin/speak   # команда speak из любой папки
speak setup      # голос (~60 МБ) и модель распознавания (~500 МБ)
speak check      # ffmpeg, claude, голос — всё ли на месте
```

Нужны `ffmpeg` (`sudo dnf install ffmpeg`) и Claude Code, в котором ты уже вошёл в аккаунт.

## Запуск

```bash
speak serve      # откроет http://127.0.0.1:8770 в браузере
```

Firefox спросит доступ к микрофону — разреши. Держи **Пробел**, пока говоришь, или нажми на микрофон
(второе нажатие — стоп).

## Настройки

Переменные окружения:

| Переменная | По умолчанию | Зачем менять |
|---|---|---|
| `SPEAK_MODEL` | `sonnet` | `haiku` — дешевле, `opus` — тщательнее разбор |
| `SPEAK_WHISPER` | `small.en` | `base.en` — в 3 раза быстрее, но хуже понимает акцент; `medium.en` — точнее и медленнее |
| `SPEAK_VOICE` | `en_US-lessac-medium` | другой голос Piper, например `en_GB-alba-medium` (потом `speak setup`) |
| `SPEAK_HOME` | `~/.local/share/speak-coach` | где хранить голоса, разговоры и тетрадь |

## Разработка

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest --cov=speak
```

Тесты подменяют Whisper, Piper и Claude заглушками (процесс собеседника — поддельным `claude` со stream-json
в `tests/fakes.py`); один тест гоняет настоящие Piper → Whisper, если модели скачаны.
